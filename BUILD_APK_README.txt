EM ALL NET MOBILE SERVICES - Android APK build

GitHub Actions workflow is included at .github/workflows/android-apk.yml.
Upload/extract all files into the ROOT of your GitHub repository (not as one ZIP file), commit to main, then open Actions > Build Android APK > Run workflow.
When complete, open the successful workflow run, scroll to Artifacts, and download EM-ALL-NET-MOBILE-SERVICES-APK. Extract the artifact ZIP to get app-debug.apk and install it on Android.
